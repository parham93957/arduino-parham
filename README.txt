Arduino Parham - نسخه آماده انتشار

فایل اصلی سایت index.html است. پوشه را در مخزن عمومی GitHub قرار دهید و در Settings > Pages گزینه Deploy from a branch را انتخاب کنید؛ Branch: main و Folder: /(root).
پس از فعال شدن Pages، آدرس سایت به شکل https://USERNAME.github.io/ خواهد بود.
برای نتیجه بهتر در گوگل، پس از انتشار سایت را در Google Search Console ثبت کنید.
